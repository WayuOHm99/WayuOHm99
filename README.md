## เกี่ยวกับผม

ผมชอบเอาปัญหาที่เจอมาลองทำเป็นระบบ ตั้งแต่หน้าเว็บ API ไปจนถึงข้อมูลข้างหลัง ถ้ามีวิธีที่ง่ายขึ้นหรือไอเดียที่ดีกว่า ก็อยากลองและค่อย ๆ ปรับให้ดีขึ้นครับ

ใช้ AI ช่วยคิด เขียน และตรวจงาน แต่ยังต้องกลับมาดูว่าโค้ดทำงานตรงที่ต้องการไหม พยายามเก็บทั้งสิ่งที่ทำได้แล้วและสิ่งที่ยังต้องแก้ไว้ในเอกสาร จะได้กลับมาทำต่อได้ง่าย

## ช่วงนี้สนใจอะไร

- **AI Agents & Skills** — ทำอย่างไรให้ AI ช่วยงานได้เป็นขั้นตอน และตรวจสอบสิ่งที่ทำได้
- **เว็บที่ใช้งานง่าย** — ปรับหน้าจอ ข้อความ และการเข้าถึงให้คนใช้งานเข้าใจได้เร็วขึ้น
- **การทดสอบและพัฒนาต่อ** — เพิ่มการตรวจที่ช่วยจับปัญหา และเก็บเหตุผลไว้ให้กลับมาทำต่อได้
